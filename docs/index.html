How it works

The radio stays dumb.
The laptop does the thinking.

One T‑TWR Plus is the base station. Its ESP32‑S3 configures the SA868 transceiver, watches the squelch line, streams received audio over USB at 16 kHz, and — when armed — plays audio into the transceiver’s mic path while it keys PTT. Everything with judgement runs on the Mac and can be swapped: speech‑to‑text, the model, the voice.

Build one

Two boards, a cable, a laptop.

Everything is in the repo: firmware, host code, the factory firmware backup, and the pin map we reverse‑checked against the Rev2.1 schematic. Receive‑only firmware has no code path that keys the transmitter, so you can start there.

LilyGO T‑TWR Plus Rev2.1

ESP32‑S3R8, 16 MB flash, SA868 VHF (134–174 MHz) or UHF (400–480 MHz). One is enough with a store‑bought handheld; two lets the test suite talk to itself.

A charged 18650 / 21700

The RF section is battery‑fed. A flat cell shows up as “SA8X8 failed” on the stock firmware, or silence and RSSI 0 on ours.

Mac with Python 3 + PlatformIO

pyserial, ffmpeg, and a Gemini key. Local whisper works for receive‑side experiments with no key at all.

  1. Find the boards

    Ports are matched by the ESP32’s MAC, so they don’t shuffle when you move a cable.

    python3 tools/ports.py

  2. Flash receive‑only, listen to the weather

    NOAA on 162.400–162.550 MHz is a legal, always‑on test signal. Open the squelch and watch the level meter.

    cd firmware && pio run -e thinkie-rx-a -t upload --upload-port $(../tools/ports.py A)
.venv/bin/python host/monitor.py A --freq 162.450 --sq 0 --wav noaa.wav --secs 30

  3. Run the loop on the speaker

    Same pipeline, reply plays from the board’s own speaker. Nothing radiates.

    .venv/bin/python host/agent.py A --freq 146.550

  4. Go on the air

    Transmit‑capable firmware boots disarmed; the agent asks you to type ARM and appends your callsign to every reply.

    .venv/bin/python host/agent.py A --freq 146.550 --callsign YOURCALL --tx
Rules of the air

It transmits. Treat it like a radio.

Receiving is unrestricted. Transmitting is where the law and the safety interlocks live — both are part of the design, not an afterthought.

Amateur 2 m is the clean path

Home‑built and modified equipment is explicitly allowed under Part 97. You need a Technician licence, a control operator present, and station ID every 10 minutes and at the end — the agent speaks your callsign for you. No broadcasting, no commercial traffic.

MURS and FRS are for certified radios

They’re licence‑free, but Part 95 requires the whole radio to be certified, and the SA868 module isn’t. We’ve run it on MURS ch 1 to prove the loop; a product for that service would be a fixed‑channel, sealed‑firmware design tested by an accredited lab.

Interlocks in firmware

Independent of anything the host does:

boots disarmed; host must arm each session (10 min TTL)forced unkey after 60 s continuous transmitunkeys the instant the USB host disappearsrefuses to key below 3.4 V batteryreceive‑only builds contain no PTT code at all

Bench hygiene

Low power, short bursts, an antenna or dummy load on the SMA every time — the SA868’s PA doesn’t like an open connector. Two boards on one desk couple at RSSI 120 through a few centimetres of PCB trace, so start with the squelch at 3.
